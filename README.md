## 🖥️ What this is

termfmt is a small library for C++ that helps you format text in the terminal. It is made for command-line tools and text-based apps that need clear output, color, and layout in the console.

It is header-only, so you do not need a separate install step for the library itself. You add the files to your project and use them in your code.

This project fits tools that show status text, logs, menus, prompts, or simple terminal screens.
